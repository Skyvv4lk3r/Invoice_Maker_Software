# Target UML design

The accompanying PDF and 28 editable PlantUML/SVG diagrams describe the complete
target application. Open `gallery.html` locally to browse the diagrams. They
include features that are still planned in this initial implementation.

Read `../ARCHITECTURE.md` and `../ROADMAP.md` for the implemented subset.
Render changed sources with PlantUML and Graphviz, then review their SVGs.
Changing a diagram does not regenerate the PDF automatically.
